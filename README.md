# Yazılım Yaşam Döngüsü Modelleri

Yazılım geliştirme yaşam döngüsü (SDLC) modellerini karşılaştıran ders ödevi.

## İçerik

Şelale, V-modeli, spiral, artımlı ve çevik gibi yazılım yaşam döngüsü modellerinin
aşamaları, birbirlerine göre avantaj ve dezavantajları ile hangi proje tiplerine
uygun oldukları incelenmiştir.

## Dosyalar

Ödev dokümanı `.docx` ve `.pdf` biçimlerinde bu depoda yer almaktadır.

> Bu depo kod içermez; yalnızca yazılı bir ders çalışmasıdır.
